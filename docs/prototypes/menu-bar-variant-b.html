What this is showing. The root menu never grows: a day with twelve meetings still shows four lines. Meetings ▸ groups by day and ends in Browse All Meetings…, which opens the output folder in Finder. Ollama ▸ carries live status plus the recovery action, so a dead server is both visible and fixable without leaving the menu. The dot beside Ollama in the root menu is the at-a-glance signal; the menu bar icon carries the same dot.

Not shown: the recording state (icon turns red, title becomes a timer, Start becomes Stop), and the degraded state where a meeting transcribed but got no summary — that meeting needs a marker in the list and a Retry summary action. Variant C in the canvas sketched both; borrow from it when wiring the list.
